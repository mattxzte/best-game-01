Prismweave — a light-routing puzzle game. Bend beams of coloured light around walls with mirrors, split them, repaint them, and wake every prism in its own colour before the moves run out. Eight hand-built levels, synthesized sound, no downloads, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

## How to play

- Click an empty cell to place a mirror. Click a mirror to turn it.
- Right-click a mirror to take it away. Every click costs one move.
- Light every prism in its own colour before the moves run out.
- Splitters divide a beam. Filters repaint it. Walls swallow it.
- R restarts the level, N goes to the next one, M toggles sound, Esc returns to the menu.
